## 已沉淀的读码思想

### 1. 框架固定 vs 自己动手（2026-11-21 确认）

- **框架固定的**（注解、API、Builder 链、模板配置）：不需要多想，会照抄 + 一句话说清"它改变了什么行为"。
- **自己写的**（名字、数值、策略）：唯一的思考对象，每个格子都要能答"为什么是这个值"。
- 面试口径：自己定的格子 = 考点；框架固定的 = 一句话带过。

### 2. 全链路分支讲解法（2026-11-22 确认，已写入 AI_CONTEXT 铁律 11）

读任何一条请求，按"命令 → 全部结局 → 每个结局的数据路径"来理解；数据编号全程跟踪，不给省略描述。
